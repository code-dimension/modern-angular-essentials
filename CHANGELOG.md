# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-20

### Added
- **Initial Release** of the **Modern Angular Essentials Pack** curated by **Code Dimension**.
- Bundled 13 powerful extensions:
  - Angular Language Service (`Angular.ng-template`)
  - ESLint (`dbaeumer.vscode-eslint`)
  - Prettier - Code formatter (`esbenp.prettier-vscode`)
  - Tailwind CSS IntelliSense (`bradlc.vscode-tailwindcss`)
  - Pretty TypeScript Errors (`yoavbls.pretty-ts-errors`)
  - GitLens — Git supercharged (`eamodio.gitlens`)
  - Spek (`kewang.spek-vscode`)
  - Copilot Theme (`BenjaminBenais.copilot-theme`)
  - Todo+ (`fabiospamponato.vscode-todo-plus`)
  - Auto Close Tag (`formulahendry.auto-close-tag`)
  - Auto Rename Tag (`formulahendry.auto-rename-tag`)
  - EditorConfig (`EditorConfig.EditorConfig`)
  - Figure (`imfeniljikadara.figure`)
- Included premium geometric abstract logo (`assets/icon.png`).
- Fully documented setup and publishing guide for both VS Code Marketplace and Open VSX.
